# Public disclosure note

This repository is intended as a publishable local implementation substrate for Austin Grandstaff's Proof-of-Improvement Persistent Transformer architecture.

Key disclosed claims in this repository:
- persistent SSD-backed graph, vector, and ledger memory can act as externalized attention;
- continual-learning updates should be proposed as transactions, not blindly applied from exposure;
- validator consensus can gate local ranker, policy, and future adapter updates;
- retrieval/ranker learning is the first mutable target before direct neural fine-tuning.

This implementation does not claim full autonomous self-training, AGI, or unsupervised weight rewriting. It is a governed local substrate for memory, retrieval, validation, and upgrade control.
